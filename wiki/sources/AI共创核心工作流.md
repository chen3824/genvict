# AI共创核心工作流 — 来源摘要

> 本页是 `raw/AI共创/AI共创工作流与工作重点 V1.0.md` 的摘要页（文件在 2026-08-17 重组中从旧名更名而来）。原件不可修改，一切主张以原件为准。

## 这份来源讲什么

从**方法论 / 流程视角**定义 AI 共创的完整工作流：11 阶段端到端流水线、配套 6 个 Stage Gate、5 条管理原则与最终闭环。

## 关键内容一览

- **核心工作流**：发现机会 → 业务诊断 → 场景评估 → AI方案 → POC → MVP → Pilot → Adoption → Scale → 能力沉淀
- **09 个编号阶段**（01 Opportunity / 02 Diagnose / 03 Evaluate / 04 Prototype·POC / 05 MVP / 06 Pilot / 07 Adoption / 08 Scale / 09 Asset），每阶段含验证问题、关注点与输出（如 AI Scenario Card、场景优先级、AI 能力资产库）。
- **Stage Gate 体系**：Gate 0 值不值得做（业务价值）→ Gate 1 AI 能不能做（POC）→ Gate 2 能不能使用（MVP）→ Gate 3 有没有业务价值（Pilot）→ Gate 4 值不值得推广（Scale）→ Gate 5 能不能沉淀复制（Asset）。
- **5 条管理原则**：业务问题优先于 AI 技术；小步快跑；POC 成功 ≠ 项目成功；项目终点不是上线而是"被使用 + 产生价值 + 可复制"；成功项目必须资产化。
- **最终闭环**：AI能力 → 业务场景 → POC → MVP → Pilot → Adoption → 业务价值 → 能力沉淀 → 复制到更多业务 → 新的 AI 场景。
