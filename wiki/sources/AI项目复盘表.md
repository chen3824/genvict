# AI项目复盘表 — 来源摘要

> 本页是 `raw/AI共创/10《AI项目复盘表 V1.0》.md` 的摘要页。原件不可修改，一切主张以原件为准。

## 这份来源讲什么

「AI共创工作体系」**模板 10**（阶段10）。项目节点/结束/终止/阶段转换时使用，从每个 AI 项目（无论成功失败）中提取经验。回答**"这个项目我们做得怎么样？下次怎么做得更好？"**

## 关键内容一览

- **五大原则**：① 复盘不是"找责任人"（blame vs learning）；② **失败必须复盘**（"公司最大的 AI 浪费是失败项目不复盘、下次还犯同样的错"）；③ 必须基于事实不基于感觉；④ 必须有改进输出（**至少 3 条可执行改进**）；⑤ 必须及时（**最佳 2 周内**，超过 1 个月价值大减）。
- **复盘四步法（核心方法论）**：回顾目标 → 评估结果 → 分析原因 → 总结经验。
- **四维度复盘**（每维 5 问 + 3 条经验）：业务 / AI技术 / 数据 / 组织。
- **五类假设验证**：业务、价值、技术、用户、组织（每类"已验证/推翻/未验证"+ 证据）。
- **复盘会议 SOP**：时长 90~120 分钟，7 段议程（开场+原则 / 回顾目标 / 评估结果 / 分析原因 / 总结经验 / 改进方向 / 沉淀与新机会）。
- **四类项目差异化复盘**：成功（经验可复用？运气成分？）/ 部分成功 / 失败（根本原因、假设推翻）/ 终止（决策是否正确、已投入能否复用）。
- **改进方向三档**：立即（1个月内）/ 中期（3个月内）/ 长期（6个月内），每项含 Owner 与截止时间。
- **复盘是飞轮起点**：复盘 → 经验 → 资产 → 下次更快启动 → 下次成功率更高；副产品是**新机会识别并回流到 01 场景发现**。
- **与效果评估的区别**：评估回答"AI 创造多少价值"，复盘回答"下次怎么做更好"。
