# AI能力资产沉淀表 — 来源摘要

> 本页是 `raw/AI共创/09《AI能力资产沉淀表 V1.0》.md` 的摘要页。原件不可修改，一切主张以原件为准。

## 这份来源讲什么

「AI共创工作体系」**模板 09**（阶段09，Gate 4 之后、Gate 5 决策）。把成功项目的经验沉淀为公司可复用的 AI 能力资产库，避免每个部门重复造轮子。回答**"这个 AI 能力能不能成为公司的组织能力？别人怎么用？"**

## 关键内容一览

- **Asset 不是项目归档**：目的（让别人能复用 vs 留存记录）、形式（可执行资产 vs 文档）、标准（可复用 vs 完整）、维护（持续更新 vs 一次性）。
- **五大原则**：① 资产必须可复用（"项目经验总结"不是资产，"能直接拿去用的 Prompt+知识库+SOP"才是）；② 资产必须有 Owner；③ 必须持续更新（版本管理+失效下线）；④ 必须可被发现；⑤ 必须有使用记录（**没人用的资产应下线**）。
- **八类 AI 能力资产**：

| 类型 | 复用方式 |
|---|---|
| AI Tool（工具/产品） | 直接使用 |
| Prompt（提示词） | 直接复用/微调 |
| Workflow（工作流） | 直接使用/改造 |
| Agent（智能体） | 直接使用/微调 |
| Knowledge Base（知识库） | 直接接入/扩展 |
| SOP（标准操作规程） | 直接使用 |
| Case Study（案例） | 学习参考 |
| 方法论（工作方法） | 借鉴应用 |

- **三 Owner 制**：资产Owner（维护）+ 业务Owner（业务正确性）+ 技术Owner（技术稳定）；"没有 Owner 的资产半年后必然失效"。
- **资产评审 8 项 checklist**（全部满足才能入库）：完整、可执行、业务正确、技术稳定、有 Owner、有使用说明、有边界说明、有版本号。
- **资产维护频率**：AI Tool 每周；Prompt/Workflow/Agent 每月；KB 每周/每月；SOP 每季度；Case Study/方法论 每年。
- **资产健康度六维评分**（1~5）：使用度、覆盖度、效果、时效性、复用度、价值。
- **Gate 5 决策**：🟢 ASSET → 沉淀为组织 AI 能力 / 🟡 SCALE MORE → 继续扩大复用 / 🔴 RETIRE → 下线。
- **飞轮起点**：项目成功→沉淀资产→资产复用→新项目更快启动→沉淀更多资产。
