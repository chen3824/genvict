## 这份来源讲什么

阿里云官方帮助中心 RAM 产品文档的整理版，覆盖：子定义与对比、创建（控制台/OpenAPI）、授权、登录、安全最佳实践、常见问题。

## 关键内容一览

- **认识 RAM 用户**：RAM 用户是访问控制（RAM）中的一种[[RAM 用户|实体身份]]，非独立账号，不拥有资源、不独立计费，默认无任何权限。
- **创建**：手动创建 / SCIM 同步 / 云 SSO 同步；按访问方式分控制台登录用户与 API 调用用户（二选一）。
- **授权**：系统策略与自定义策略；账号级/资源组级授权范围；可通过用户组统一授权。
- **登录**：`<UserName>@<AccountAlias>.onaliyun.com`；通用/专属登录链接。
- **安全最佳实践**：避免主账号日常运维、强制 MFA、最小权限、优先 STS Token 临时凭证、定期审计。
- **常见问题**：权限不足排查（权限诊断）、`LimitExceeded.User.Policy` 配额超限等。
