# Wiki 操作日志

> **按时间顺序、只追加**的操作记录：ingest（摄入）、query（查询）、lint（体检）。
> 每一条以固定前缀开头，便于用 unix 工具解析，例如：
> `grep "^## \[" log.md | tail -5` 查看最近 5 条记录。

## 记录格式

```
## [YYYY-MM-DD] ingest | <来源标题>
- 新增页面：
- 更新页面：
- 备注：
```

```
## [YYYY-MM-DD] query | <问题摘要>
```

```
## [YYYY-MM-DD] lint | <发现的问题摘要>
```
