# RAM 用户

阿里云访问控制（RAM）中的一种**实体身份类型**，有确定的身份 ID 与[[身份凭证]]，通常与某个确定的人或应用程序一一对应。

## 核心特点

- 由主账号（或拥有 RAM 管理员权限的 RAM 用户/角色）创建，创建后**归属主账号，不是独立阿里云账号**。
- 不拥有资源、不能独立计费，由主账号统一付费（来源 §1.1）。
- 默认无任何权限，必须经[[权限策略]]授权后才能访问资源。
- 创建本身不产生费用。

## 与主账号的区别

| 维度 | 主账号 | RAM 用户 |
| --- | --- | --- |
| 账号性质 | 独立阿里云账号 | RAM 实体身份，非独立账号 |
| 资源与权限 | 拥有全部资源、全部权限 | 无资源、默认无权限 |
| 计费 | 独立计量计费 | 由主账号统一付费 |
| 建议用途 | 仅授权/付费/账号管理等关键操作 | 日常开发、运维、部署 |

主账号类似 Linux `root`，权限极大**不适合日常使用**；需授权他人时应建 RAM 用户而非共享主账号密码。

## 创建途径

1. **手动创建**：控制台手动创建（为员工建登录账号、为应用建独立凭证、按角色授权）。
2. **SCIM 同步**：从企业 [[身份体系|IdP]] 同步，**不支持手动删除**。
3. **云 SSO 同步**：必须通过云 SSO 登录，不能用用户名密码直登；删除同步任务后才可手动删除。

按访问方式分：
- **控制台登录用户**（员工）：可启用 MFA。
- **API 调用用户**（程序/脚本）：创建 [[身份凭证#AccessKey|AccessKey]]，不设控制台密码。
官方建议一位用户仅设一种访问方式，人员与程序用户分离。
