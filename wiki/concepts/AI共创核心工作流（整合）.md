# AI共创核心工作流（整合）

> 综合两个来源：[[AI共创核心工作流]]（方法论/流程视角）与 [[AI共创岗位核心工作流与工作重点]]（岗位/运营视角）。
> 两者无冲突、互为补充：前者回答"工作流长什么样"，后者回答"岗位上日常管什么、关注什么"。

## 一、一句话定义

AI 共创 = **一套端到端流水线（机会→落地→沉淀） + 一个持续运营的岗位节奏**。核心是让 AI 在业务中真正产生价值。

## 二、整合后的完整工作流

```
发现机会 → 业务诊断 → 场景评估 → AI方案 → POC → MVP → Pilot → Adoption → Scale → 能力沉淀
```

岗位 6 类核心工作（岗位视角）与流水线阶段（流程视角）的对应关系：

| 岗位核心工作 | 对应流程阶段 | 主要产出 |
|---|---|---|
| 1 找场景 | 01 Opportunity | AI Opportunity |
| 2 定问题 | 02 Diagnose / 03 Evaluate | AI Scenario Card、场景优先级 |
| 3 做共创 | AI方案 / 04 Prototype·POC / 05 MVP | POC 结果、MVP |
| 4 推落地 | 06 Pilot / 07 Adoption / 08 Scale | 采用数据、规模化项目 |
| 5 看结果 | 06/07 效果衡量 | 业务价值数据 |
| 6 做沉淀 | 09 Asset | AI 能力资产 |

## 三、Stage Gate 体系

| Gate | 核心问题 | 主要验证 |
|---|---|---|
| Gate 0 | 值不值得做？ | 业务价值 |
| Gate 1 | AI 能不能做？ | POC |
| Gate 2 | 能不能使用？ | MVP |
| Gate 3 | 有没有业务价值？ | Pilot |
| Gate 4 | 值不值得推广？ | Scale |
| Gate 5 | 能不能沉淀复制？ | Asset |

## 四、核心管理对象 ↔ 流程产出

岗位视角的 5 类长期管理对象与流水线产出一一对应：

| 管理对象 | 对应流程产出 |
|---|---|
| AI Opportunity Pool | 01 收集的机会池 |
| AI Scenario Map | 02/03 产出的 Scenario Card 与优先级 |
| AI Project Portfolio | POC→Scale 各阶段在推项目 |
| AI Value Dashboard | Pilot/Adoption 效果衡量的价值数据 |
| AI Asset Library | 09 沉淀的能力资产库 |

## 五、运营节奏

- **每周**：新场景、在推 POC/MVP/Pilot、阻塞问题、用户反馈、新 AI 能力
- **每月**：Portfolio、场景数量、POC 成功率、Pilot 数量、活跃用户、Adoption、效率提升、业务价值、失败复盘
- **每季度**：公司 AI 能力地图、高价值场景、复用率、规模化项目、组织成熟度、下一季方向

## 六、核心管理原则

1. **业务问题优先**：不为用 Agent 而找场景，从业务问题出发选 AI 能力
2. **小步快跑**：先验证，再投入
3. **POC 成功 ≠ 项目成功**：须走到 Adoption + Business Impact
4. **项目终点不是上线**：而是"被使用 + 产生价值 + 可以复制"
5. **成功项目必须资产化**：避免每个部门重复造轮子

## 七、最终目标与闭环

- **岗位目标升级**：帮助业务做 AI 项目 → **建立公司 AI 业务创新与落地机制**
- **能力进化**：个人能力 → 项目能力 → 团队能力 → 组织能力
- **业务闭环**：AI能力 → 业务场景 → POC → MVP → Pilot → Adoption → 业务价值 → 能力沉淀 → 复制到更多业务 → 新的 AI 场景
