# AI共创模板体系 — 综述

> 本页是 `raw/AI共创/` 目录下 **12 个编号模板**（01–12）的体系综述。单个模板的内容见各自来源摘要页。

## 一、体系是什么

一套面向「AI 共创」岗位的**端到端工作体系模板**：从场景发现到能力沉淀，每个阶段一张模板，配套 5 道 Stage Gate 决策机制，形成"单项目执行 → 公司级管理 → 项目全景视图"三个层次。

```
单项目执行层（01–10）：Discovery → POC → MVP → Pilot → Adoption → Scale → Asset
公司级管理层（11）    ：AI 项目组合管理（哪些做、哪些停、资源怎么配）
项目视图层（12）      ：每个项目一页纸全景（Canvas）
```

## 三、Stage Gate 决策链

| Gate | 核心问题 | 关键证据 | 决策 |
|---|---|---|---|
| Gate 0 | 值不值得做？ | Scenario + Score | GO / HOLD / KILL |
| Gate 1 | AI 能不能做？ | POC Result | GO / ITERATE / KILL |
| Gate 2 | 能不能用？ | MVP | GO / ITERATE / KILL |
| Gate 3 | 有没有价值？ | Pilot Data | SCALE / ITERATE / STOP |
| Gate 4 | 能否复制？ | Scale Data | ASSET / SCALE MORE / RETIRE |
| Gate 5 | 能不能沉淀复制？ | Asset | （资产决策） |

**三条决策原则**：没有证据不进入下一阶段；失败也是正常结果；投入逐阶段增加、越往后证据要求越高。

## 四、阶段证明命题逐步升级

能不能做（POC）→ 能不能用（MVP）→ 有没有价值（Pilot）→ 会不会持续用（Adoption）→ 创造多少价值（Value）→ 沉淀为能力（Asset）

一句话对照：**POC 证明"能"，MVP 证明"能用"，Pilot 证明"有价值"，Adoption 证明"被持续使用"，Asset 证明"成为组织能力"。**

## 五、体系飞轮

```
业务问题 → AI假设 → POC → MVP → Pilot → Adoption → Scale → Asset
   ↑                                                        │
   └── 效果评估 + 复盘 ←────────── 沉淀资产 + 复用 ←─────────┘
       （新机会回流到 01 场景发现，飞轮加速）
```

## 六、核心方法论沉淀

- **指标四分类**（POC 提出，全体系复用）：Task Success / Quality / Efficiency / Cost（Adoption 阶段扩展为 Adoption/Efficiency/Quality/Business Impact）
- **对照组思维**：POC 人工对照组 → MVP 三轮测试 → Pilot 对照组设计 → 效果评估对照组原则，贯穿全程
- **假设驱动**：Hypothesis → Evidence → Result，每阶段价值假设有固定句式
- **量化底线**：没有 Baseline 不能谈效果；没有对照组结论不可信；"效果不错"不是指标
- **人机协作边界**：AI 负责"生产和辅助判断"，人负责"最终业务责任"
- **防失败设计**：每模板含常见错误清单；复盘强调"失败必须复盘"
