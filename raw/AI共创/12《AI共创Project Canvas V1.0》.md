# 12《AI共创Project Canvas V1.0》

> **AI共创工作体系｜阶段12**
>
> **适用阶段：贯穿项目全周期，每个AI项目都需要维护的一页纸全景视图。**
>
> **核心目的：把一个AI项目所有关键要素浓缩到一页，让任何人5分钟就能看懂这个项目。**
>
> **版本：V1.0**

---

# 一、Project Canvas在AI共创体系中的位置

完整流程：

```
单项目管理：
01 场景发现 → 02 评分 → 03 Gate 0 → 04 POC → 05 Gate 1 →
06 MVP → 07 Gate 2 → 08 Pilot → 09 Gate 3 → 10 Adoption →
11 Gate 4 → 12 Scale → 13 Asset

组合管理：
11 AI项目Portfolio

单项目全景：
12 AI共创Project Canvas ← 当前
```

前面11个模板都在回答：

> **"项目不同阶段怎么做？"**

Canvas回答：

> **"任何一个AI项目，用一页纸说清楚它是什么、解决什么、怎么验证、进展如何。"**

Canvas不是新流程，而是：

> **把前面所有模板的精华，浓缩成一张可随时查阅的"项目身份证"。**

---

# 二、Canvas是什么

## Canvas的本质

> **一个AI项目的一页纸全景视图。**

类似Business Model Canvas之于商业模式。

---

## Canvas的作用

- 立项时：用Canvas快速定义项目
- 推进中：用Canvas追踪状态
- 评审时：用Canvas快速汇报
- 资产化：用Canvas沉淀项目精华
- Portfolio：每个项目一张Canvas

---

## Canvas与其他模板的关系

| 模板 | 作用 | 与Canvas关系 |
|---|---|---|
| 01 场景发现 | 业务访谈 | Canvas继承业务问题 |
| 02 评分 | 优先级 | Canvas显示优先级 |
| 03 Stage Gate | 决策 | Canvas显示当前Gate |
| 04 POC | 技术验证 | Canvas显示AI能力 |
| 05 MVP | 业务闭环 | Canvas显示工作流 |
| 06 Pilot | 业务价值 | Canvas显示Baseline/Target/Actual |
| 07 Adoption | 使用深度 | Canvas显示Adoption指标 |
| 08 效果评估 | 价值量化 | Canvas显示ROI |
| 09 资产沉淀 | 组织能力 | Canvas显示沉淀资产 |
| 10 复盘 | 经验 | Canvas显示复盘结论 |
| 11 Portfolio | 组合管理 | Portfolio由多个Canvas组成 |

# 三、Canvas的核心原则

## 原则1：必须一页纸

Canvas的价值在于：

> **浓缩。**

如果一页放不下，说明：

> **你还没想清楚重点是什么。**

---

## 原则2：必须5分钟能看懂

Canvas不是给项目团队看的。

是给：

- 管理层
- 新加入的同事
- 跨部门协作方
- Portfolio评审会

看的。

必须5分钟内能让人理解：

> 这个项目是什么、解决什么、怎么验证、进展如何。

---

## 原则3：必须随阶段更新

Canvas不是"立项时填一次"。

每个阶段结束、每个Gate决策后，必须更新。

不同阶段Canvas的填法不同：

| 阶段 | Canvas状态 |
|---|---|
| Discovery | 假设为主 |
| POC | 假设 + 验证 |
| MVP | 方案 + 闭环 |
| Pilot | Baseline + Target + Actual |
| Adoption | Adoption + Business Impact |
| Scale | ROI + 复制情况 |
| Asset | 资产 + 复用 |

---

## 原则4：必须由AI共创负责人维护

Canvas不是文档管理员整理的。

而是：

> **AI共创负责人亲自维护、亲自更新的项目视图。**

---

## 原则5：Canvas是"对齐工具"

Canvas最重要的价值是：

> **让所有相关方对项目认知一致。**

业务Owner、技术团队、管理层、AI共创团队 看的是同一张Canvas。

避免：

> 每个人对项目理解都不一样。

# 二十、Canvas维护原则

## 原则1：每个项目一张Canvas

不能一个项目多张，也不能多项目共用一张。

---

## 原则2：Canvas必须最新

超过2周没更新的Canvas，等于失效。

---

## 原则3：Canvas必须由AI共创负责人维护

不能让实习生整理。

每个版本的Canvas必须保留。

形成项目"成长档案"。

## 原则5：Canvas必须可对比

不同项目的Canvas要能横向对比。

否则Portfolio失去意义。
