用户需求：ram 子账号可下单/创建资源，只看原价、看不到优惠折扣，需要加一条自定义权限策略：

{
  "Version": "1",
  "Statement": [
    {
      "Effect": "Deny",
      "Action": "bss:QueryPrice",
      "Resource": "*"
    }
  ]
}

配置后，购买页、续费页、购物车、价格计算器及 API 询价均只显示原价，不显示折后价和优惠金额，但不影响正常下单。

关于 ram 子账号不能支付、由主账号(MA)统一支付：
这步靠结算关系控制，不是 RAM 权限。
您在资源管理控制台，将该成员账号的结算方式设为财务托管。
设为财务托管后，成员账号仅保留下单、查看消费、资源操作权限，订单费用由主账号统一支付，成员账号本身无法完成付款。
财务托管开通与解除帮助链接：
https://help.aliyun.com/zh/user-center/establish-or-remove-a-trusteeship-1
